04 / SCIENTIFIC METHOD

Make different observations comparable.

A common grid creates consistent units. Validated sensor adjustment is a separate scientific task.

CALIBRATION NOT VALIDATED

Overlap validation workbench

Import a documented common-observation daily metric bundle to run the baseline model.

Measured

Observation counts, coordinates, time, source confidence, FRP and occupied cell-days. FRP describes radiative power, not burned area or human exposure.

Inferred

Spatial co-occurrence and repeated observations identify investigation candidates. Land cover and independent reports can strengthen or challenge a hypothesis.

Not established

Ignition cause, number of independent fires, burned hectares, emissions, lives saved and future spread cannot be established by these hotspot records alone.

05 / FROM DATA TO DECISIONS

Useful at the scale of a decision.

Start with a documented regional pilot. Validate the result, then expand using the same data contract.

Impact to measure in a pilot: time to find a documented historical period; source-trace accuracy; agreement with an independent incident register; task completion by actual land managers. No impact percentage has been measured yet.
